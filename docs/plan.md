# Plan: Pawzz Foundation Intern Assignment

**Role:** Product Development, Design & AI Systems Intern
**Deadline:** 11 Nov 2026 (today is 10 Nov, so about 1.5 days left)
**Expected effort:** 4-5 hours of focused work
**Goal:** Show that I can take a founder's rough idea and turn it into a polished, working digital experience plus a repeatable AI system.

## 1. What is being asked

| # | Task | Deliverable |
|---|------|-------------|
| 1 | Practo for Animals: MVP homepage / search page | Polished wireframe or clickable prototype + explanation of MVP features, filters, provider info, CTAs, mobile experience |
| 2 | AI Education: course landing page | Landing-page prototype + page structure, value proposition, CTAs, lead-capture journey |
| 3 | AI content creation system | One sample carousel made via the proposed workflow + workflow diagram/explanation |
| - | Written summary | Tools, tech stack, CTAs, automation workflow, links to prototypes |

## 2. How I will be judged (and where to spend time)

| Criterion | Weight | Implication |
|-----------|--------|-------------|
| UI/UX and visual design quality | 30% | Biggest chunk of effort goes into the two designs looking genuinely polished |
| AI workflow and automation | 25% | Workflow must be real and demonstrable, not only described |
| Product thinking and CTA strategy | 20% | Every CTA needs a reason and a defined next step |
| Technical execution and tool selection | 15% | Justify each tool; ship live links |
| Initiative and communication | 10% | Clear, concise write-up; a short, confident submission message |

## 3. Key decisions

1. **Format of prototypes:** build both designs as live, responsive web pages (single-file HTML/Tailwind or a Lovable/Replit build), deployed to a public URL. This shows design and technical skill at once, and a link is easier for the founder to open than a Figma file. Add a Figma frame or screenshot set only if time remains.
2. **Carousel:** make it about something that proves the system works and is on-brand for Pawzz, for example "5 signs your pet needs a vet visit" (ties to Task 1). Produce it end to end through the proposed workflow and keep screenshots of each stage as evidence.
3. **Single deliverable doc:** one short README/PDF with links, the tool stack, CTA table, and the workflow diagram.
4. **Brand:** warm, trustworthy, friendly palette for the animal-care product; a separate, more modern/techy look for the AI education page so the two feel like distinct products.

## 4. Time budget (about 5 hours)

| Block | Time |
|-------|------|
| Research and planning: look at Practo, Zomato, Petco-style listings; define scope | 30 min |
| Task 1: Practo for Animals homepage and search page | 100 min |
| Task 2: AI course landing page | 60 min |
| Task 3: carousel workflow, build, and sample | 70 min |
| Write-up, diagram, deploy, QA on mobile | 40 min |
| Buffer | 20 min |

## 5. Risks and mitigations

- **Over-polishing one task:** time-box each block and move on at the limit.
- **Live links break:** test every link in an incognito window and on a phone before sending.
- **AI-generated look:** use real layout hierarchy, consistent spacing and a deliberate palette; avoid default template feel.
- **Workflow only on paper:** run at least the Claude to Canva/Figma path for real and capture screenshots.
- **Dummy data looks fake:** use realistic, clearly labelled sample providers and avoid real clinic names or claims.
